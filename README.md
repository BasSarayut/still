# still. — Wallpaper studio

เว็บภาษาไทยสำหรับสร้างวอลเปเปอร์ Lock Screen จากรูปและข้อความของผู้ใช้ ตามเทมเพลตเครื่องเล่นเพลงที่ตกลงไว้ ใช้งานบน iPhone และคอมพิวเตอร์ โดยไม่ต้องสมัครสมาชิก

เลือกภาษาไทย English หรือ日本語ได้จากเมนูด้านบน ครอบคลุมเครื่องมือ วิธีใช้งาน สถานะ และข้อความผิดพลาด เว็บจำภาษาในเบราว์เซอร์โดยแยกจากงานวอลเปเปอร์ การสลับภาษาจะไม่แปลหรือแก้ชื่อเพลง ศิลปิน เครดิต และข้อความตกแต่งในไฟล์ PNG

## เริ่มใช้งาน

ต้องใช้ Node.js 22.12 ขึ้นไป (หรือ Node.js 20.19 ขึ้นไป)

```sh
npm install
npm run dev
```

เปิด `http://localhost:5173` บนคอมพิวเตอร์ ส่วน iPhone ที่ใช้ Wi-Fi เดียวกัน ให้เปิด Network URL ที่ Vite แสดงใน Terminal ต้องเปิดโปรเซส dev server ไว้และอนุญาตการเชื่อมต่อเครือข่ายในระบบปฏิบัติการ

```sh
npm run build
npm run preview
```

โฟลเดอร์ `dist/` สามารถนำไปวางบน static hosting ได้ ไม่ต้องมี backend, API key หรือ environment variables ใช้ HTTPS บนเว็บไซต์จริงเพื่อรองรับ native sharing ของเบราว์เซอร์

## สิ่งที่ทำได้

- ทุกเทมเพลตใช้ Studio ร่วมกัน: จอกว้างแสดงคลังสไตล์ด้านซ้าย พรีวิวตรงกลาง และเครื่องมือด้านขวา ส่วนจอเล็กใช้คลังสไตล์เลื่อนแนวนอน แต่ละเทมเพลตแสดง preset และเครื่องมือของตัวเอง
- ทุกเทมเพลตเลือกฟอนต์ได้ 16 แบบ พร้อมกลุ่มแนะนำตามเทมเพลต (Album Cover แนะนำตามสไตล์ที่เลือก): ไทย Anuphan, Kanit, Mali, Noto Sans Thai และ Noto Serif Thai; เรียบ DM Sans และ Space Grotesk; หัวเรื่อง Oswald; คลาสสิก Playfair Display และ Cormorant Garamond; พิมพ์ดีด Roboto Mono รวมตัวเลือกเดิม ฟอนต์อังกฤษมีฟอนต์ไทยสำรองที่เข้ากับแนวเดียวกัน ไฟล์ฟอนต์ให้บริการจากเว็บเองผ่านแพ็กเกจ Fontsource
- เลือกรุ่น iPhone เพื่อกำหนดขนาด PNG และสัดส่วนพรีวิว
- อัปโหลด JPG, PNG, WebP สูงสุด 30 MB พร้อมลากวางบนคอมพิวเตอร์
- ครอปรูปเป็นสี่เหลี่ยม เลื่อนรูปบนพรีวิวด้วยเมาส์/นิ้วหรือปุ่มลูกศร และซูม 1–4 เท่า
- แก้ชื่อเพลง ศิลปิน เวลาปัจจุบัน และความยาวเพลง โดยตรวจสอบรูปแบบเวลา
- ดึงสีจากรูปสูงสุด 6 สี เลือกสีพื้นหลังเอง และเลือกสีข้อความ/ไอคอนหรือใช้สีอัตโนมัติ
- เปิด–ปิด Color Palette และเครดิตที่แก้ไขได้
- แสดงนาฬิกาและวิดเจ็ตจำลองเฉพาะบนพรีวิว ไม่ติดใน PNG
- ดาวน์โหลด PNG และเปิด native share เมื่อเบราว์เซอร์รองรับการแชร์ไฟล์
- บันทึกงานล่าสุดอัตโนมัติ รวมรูป ข้อความ สี การครอป และรุ่นเครื่อง

ชื่อเพลงยาวลดขนาดก่อน แล้วขึ้นได้สองบรรทัด หากยังยาวเกินพื้นที่จะตัดท้ายด้วย … ส่วนศิลปินและเครดิตจำกัดให้อยู่ภายในพื้นที่ของตัวเอง

## เทมเพลต Music Player

เครื่องเล่นเพลงแบบเดิมและ Now Playing รวมเป็นเทมเพลตเดียวแล้ว เลือกสไตล์เริ่มต้น **Classic / Now Playing / Minimal** แล้วปรับต่อในหมวดเพลงและสีได้

- พื้นหลังสีล้วน ไล่สีสองสีพร้อมปรับทิศทาง หรือธีมมืดที่ดึงสีจากภาพพร้อมปรับความเข้ม
- กำหนดสีข้อความและไอคอนเองได้ทุกสไตล์ หรือใช้สีอัตโนมัติ
- ปรับขนาดรูป มุมโค้ง เงา ตำแหน่งชุดเครื่องเล่น และระยะรูปกับข้อความ ระบบจัดให้องค์ประกอบอยู่ในภาพ
- ชื่อเพลงและศิลปินเลือกฟอนต์ ขนาด น้ำหนัก และสีแยกกัน พร้อมจัดชิดซ้ายหรือกึ่งกลาง
- เปิด–ปิดแถบเวลาและตัวเลขเวลา เลือกแสดงความยาวเพลงหรือเวลาที่เหลือ
- ปุ่มเต็มรูปแบบ แบบย่อ หรือซ่อน เลือกเล่น/หยุด กรอบวงกลม และขนาดปุ่มได้ พร้อมซ่อนหัวใจ
- Color Palette เลือกได้ 7 รูปแบบ: แถบพร้อมรหัส, จุดสี, แถบไล่สี, ริบบิ้นแนวตั้ง, จุดเชื่อมเส้น, สวอตช์มีเลข หรือสีเด่น + จุดเสริม ปรับจำนวนสี (3–6 สีที่เด่นสุดในรูป), การเรียงลำดับ (เด่นสุดก่อน, มืดไปสว่าง หรือตามวงล้อสี), ขนาดและระยะห่างได้อิสระ ใช้สวิตช์แสดง Color Palette เพื่อซ่อนทั้งชุด

การเลือกสไตล์เริ่มต้นจะตั้งค่ารูปแบบเครื่องเล่นใหม่ โดยเก็บรูป การครอป ข้อความ สีพื้นหลังที่เคยเลือก และเครดิตไว้ งาน Now Playing ที่บันทึกไว้ก่อนหน้านี้จะเปิดเป็นสไตล์มืดใน Music Player อัตโนมัติ ส่วน Polaroid และ Album Cover ยังเป็นเทมเพลตแยกกัน

## เทมเพลต Polaroid

เลือกสไตล์เริ่มต้น **Classic / Clean / Diary / Cinema / Noir / Postcard / Scrapbook / Formal** แล้วปรับรายละเอียดในหมวดเพลงได้

- Classic: กรอบสีอ่อนพร้อมแถบเพลง, Clean: กระดาษเรียบและข้อความกึ่งกลาง, Diary: กระดาษครีมเอียงพร้อมเทปและพื้นตาราง, Cinema: ภาพแนวนอนพร้อมคำบรรยาย, Noir: กระดาษเข้มและภาพแนวตั้ง, Postcard: กระดาษน้ำตาลอุ่นสไตล์โปสการ์ด, Scrapbook: สีสันสดใสพร้อมมุมยึดรูปและเทป, Formal: กระดาษไอวอรี่จัดกึ่งกลางแบบเรียบหรู
- เลือกสัดส่วนรูป 1:1, 3:4 หรือ 16:9 ปรับขนาด ขอบกระดาษ พื้นที่ข้อความ มุมโค้ง เงา ตำแหน่ง และการเอียง ±10°
- สีกระดาษและหมึกแยกจากสีพื้นหลัง เลือกหมึกอัตโนมัติตามสีกระดาษหรือกำหนดเอง เลือกพื้นผิวกระดาษเรียบ ใยกระดาษ หรือกระดาษเก่าได้ (ใช้ seed คงที่ พรีวิวกับ PNG จึงเหมือนกัน)
- ชื่อเพลงและศิลปินเลือกฟอนต์ (รวมฟอนต์ลายมือ) ขนาด น้ำหนัก ตัวเอียง และสีแยกกัน พร้อมจัดชิดซ้าย กึ่งกลาง หรือชิดขวา ข้อความยาวตัดท้ายด้วย …
- เลือกเทปด้านบนหรือสองมุมและสีเทป เปิดมุมยึดรูปสามเหลี่ยมที่ขอบภาพได้ เพิ่มวันที่/โน้ต เลือกพื้นเรียบ ตาราง หรือจุด และปรับ Color Palette ได้ 7 รูปแบบเหมือน Music Player (ดูหัวข้อด้านบน)
- เปิด–ปิดแถบเวลา ตัวเลขเวลา และไอคอนหยุดได้ เมื่อซ่อนแถบเวลา ค่าช่องเวลาจะไม่ขัดขวางการดาวน์โหลด
- การ์ดปรับขนาดและตำแหน่งให้พอดีกับหน้าจอ พื้นที่ข้อความขยายเมื่อจำเป็น พรีวิวครอปรูปตามสัดส่วนและการเอียงเดียวกับ PNG

การเลือกสไตล์เก็บรูป การครอป ข้อความ วันที่/โน้ต สีพื้นหลัง และเครดิตไว้ การปรับแต่งบันทึกอัตโนมัติ งาน Polaroid เดิมเปิดด้วย Classic พร้อมสถานะแถบเวลาและไอคอนที่เคยเลือก

## เทมเพลต Album Cover

เลือก **Album Cover (ปกเพลง)** แล้วเลือก Minimal Gallery, Full Photo, Swiss Typography, Indie Film, Vinyl Sleeve หรือ Dreamy Ambient จากคลังสไตล์ โดยยังมี Classic, Poster, Cassette และ Zine ให้ใช้ต่อ

- ส่งออกปกจัตุรัส 1080, 2400 หรือ 3000 px หรือวอลเปเปอร์ขนาด iPhone ที่เลือก กำหนดขนาดเองได้ 320–4096 px ต่อด้าน
- แต่ละสไตล์มีการจัดวางสมดุล ข้อความด้านบน และข้อความด้านข้าง โหมด iPhone จัดองค์ประกอบเริ่มต้นให้เว้นพื้นที่นาฬิกา และจำตำแหน่ง ขนาด และการครอปแยกจากจัตุรัส ข้อความใช้ร่วมกัน
- คอมพิวเตอร์จอกว้างมีคลังสไตล์ ภาพตัวอย่าง และแผงปรับแต่งสามคอลัมน์ หน้าจอเล็กเรียงแนวตั้งพร้อมคลังสไตล์เลื่อนด้านข้าง
- ดึงชุดสีจากรูปเมื่ออัปโหลด เลือกสีที่แนะนำหรือกำหนดสีพื้นหลังเองได้
- ปรับพื้นที่สีด้านบนตั้งแต่ 20–80% ภาพด้านล่างครอปตามพื้นที่โดยไม่ยืดภาพ พร้อมลากจัดตำแหน่งและซูม 1–4 เท่า
- สไตล์ใหม่ปรับตำแหน่งและขนาดกรอบรูปได้อิสระ พร้อมหมุน มุมโค้ง ขอบ และความโปร่งใส พื้นหลังมีสีพื้น ไล่สี และภาพเบลอ
- ปรับ Grain, Fade, Vignette, Light leak และเงาให้อ่านข้อความง่าย เพิ่มเส้น เทป ฉลาก หรือกรอบฟิล์ม พร้อมเลือกสีและความเข้ม
- เริ่มจากข้อความตัวอย่าง 4 ชิ้น เพิ่มได้สูงสุด 12 ชิ้น แต่ละชิ้นแก้ข้อความหลายบรรทัด เลือกฟอนต์ 16 แบบ ขนาด น้ำหนัก ตัวเอียง สี ความทึบ การจัดแนว ตำแหน่ง ความกว้าง ระยะตัวอักษร และระยะบรรทัดได้แยกกัน
- ฟอนต์เป็นฟอนต์ระบบ Noto Sans Thai/JP และฟอนต์ลายมือ Caveat ที่ให้บริการจากเว็บเอง ไม่เรียกบริการฟอนต์ภายนอก
- ซ่อนหรือลบข้อความได้ ข้อความและการตั้งค่าปกบันทึกในเครื่องอัตโนมัติแยกจากข้อมูลเพลงของเทมเพลตเดิม
- เลือกและลากข้อความบนภาพ หรือใช้ลูกศรขยับทีละ 0.5% (Shift: 5%) ทำสำเนา เรียงหน้า–หลัง ล็อกการลาก หมุน และเพิ่มเงาหรือเส้นขอบได้
- Undo/Redo เก็บประวัติระหว่างปรับปกในรอบปัจจุบัน บันทึกสไตล์ส่วนตัวได้สูงสุด 20 แบบในเบราว์เซอร์ รวมสีและการจัดวางทั้งสองสัดส่วน โดยไม่เก็บรูปไว้ใน preset
- พรีวิวและ PNG ใช้ตัววาดเดียวกัน โหมดปกจัตุรัสไม่มีนาฬิกาจำลองและไม่ใช้ช่องเวลาเพลง

## เทมเพลต Concert Ticket

เลือก **Concert Ticket (บัตรคอนเสิร์ต)** จากเมนูเทมเพลต แล้วเริ่มจาก **Photo Pass / Classic Stub / Midnight Live**

- บัตรแนวตั้งหรือแนวนอน ปรับขนาด ตำแหน่ง ความเอียง มุม และเงา พร้อมครอปรูปในพรีวิว
- แก้ชื่อช่องและข้อความชื่องาน ศิลปิน วันที่ เวลา สถานที่ ประตู โซน แถว ที่นั่ง ผู้ถือบัตร หมายเลขบัตร และโน้ต เก็บเลขศูนย์นำหน้าได้ เช่น `007`
- แต่ละช่องเปิด–ปิด จัดลำดับ และปรับฟอนต์ ขนาด น้ำหนัก สี และการจัดแนวได้ ช่องที่ซ่อนจะจัดเรียงพื้นที่ใหม่ ข้อความยาวจะขึ้นบรรทัดหรือลดขนาด และตัดท้ายด้วย … เมื่อยังเกินพื้นที่
- หางบัตรเลือกด้านและสัดส่วนได้ ใช้ข้อมูลโซน/แถว/ที่นั่งจากส่วนหลักอัตโนมัติ หรือเขียนข้อความเฉพาะบนหางบัตร แนวนอนจะแสดงชื่องานกับวันที่ซ้ำด้วย
- เลือกรอยปรุแบบเส้นประ/รูเจาะ/ไม่มี พร้อมขนาด ระยะห่าง ความเข้มหมึก และรอยเว้าครึ่งวงกลม
- แยกสีพื้นหลัง ตัวบัตร หางบัตร หมึก และสีเน้น ใช้สีจากรูปได้ เลือกกระดาษเรียบ ใยกระดาษ หรือกระดาษเก่า พร้อมปรับความเข้มพื้นผิว
- เปิด–ปิดบาร์โค้ดตกแต่งและตราข้อความ เช่น VIP / ADMIT ONE บาร์โค้ดเป็นภาพตกแต่งสำหรับบัตรเก็บความทรงจำ
- ปิดรูปภาพเพื่อส่งออกบัตรข้อความล้วนได้ โดยไม่ต้องอัปโหลดรูป

การเปลี่ยนสไตล์เก็บรูป การครอป ชื่อช่อง ข้อความ ลำดับและการแสดงช่อง ข้อความหางบัตร และข้อความตราที่กรอกไว้ พร้อมบันทึกงานอัตโนมัติในเครื่อง สลับภาษาไทย/อังกฤษ/ญี่ปุ่นได้โดยข้อความบนบัตรไม่เปลี่ยน พรีวิวและ PNG ใช้ตัววาดเดียวกัน รวมถึงลายกระดาษ นาฬิกาจำลองไม่ติดในไฟล์ส่งออก

## การจัดการรูปและข้อมูล

ใช้ React + TypeScript + Vite, Canvas 2D, IndexedDB และไอคอน Lucide ไม่มีการส่งรูปหรือข้อความออกจากเครื่อง ไม่มี analytics และฟอนต์ทดแทนให้บริการจากไฟล์ของเว็บเอง ไม่มีการเรียก Google Fonts ขณะใช้งาน

รูปที่นำเข้าจะปรับด้านยาวไม่เกิน 2,400 พิกเซลเพื่อควบคุมหน่วยความจำ และแปลงเป็น PNG ก่อนเก็บใน IndexedDB ตัวข้อมูลภาพจัดเก็บเป็น ArrayBuffer เพื่อรองรับ WebKit ในบริบทที่ไม่สามารถจัดเก็บ Blob ได้ จัดคิวการเขียนเพื่อป้องกันงานเก่าทับงานใหม่

พรีวิวและไฟล์ส่งออกใช้ `src/renderer.ts` ร่วมกัน นาฬิกาและวิดเจ็ตเป็น DOM อีกชั้นหนึ่ง การส่งออกจะรอฟอนต์ที่ต้องใช้ก่อนวาดภาพ อุปกรณ์ Apple ใช้ฟอนต์ระบบ ส่วนฟอนต์ไทยและญี่ปุ่นมี Noto Sans เป็น fallback โดยไม่แจกจ่าย SF Pro

ข้อมูลเก็บแยกตาม browser และ origin เช่น localhost กับ Network URL จะมีงานล่าสุดคนละชุด ไม่มีการซิงก์ข้ามเครื่อง การล้างข้อมูลเว็บไซต์ โหมดส่วนตัว หรือระบบคืนพื้นที่อาจลบงานได้ หากบันทึกไม่ได้จะแสดงสถานะให้ดาวน์โหลดไว้แทน

## ทดสอบ

```sh
npm test
npx playwright install chromium webkit
npm run test:e2e
npm run build
```

Unit tests ตรวจการครอปไม่ออกนอกภาพ ตำแหน่งองค์ประกอบทุกรุ่น เวลา สีข้อความ และการรับมือข้อมูลบันทึกที่เสียหาย

Browser tests ใช้ Chromium บน desktop และ WebKit จำลอง iPhone ตรวจอัปโหลด เลื่อน/ซูม ชื่อเพลงหลายภาษา ขนาด PNG จริง สีพิกเซลหลังครอป ภาพส่งออกเหมือนกันไม่ว่าจะเปิด/ปิดนาฬิกาจำลอง การกู้คืนงานหลัง reload และไฟล์รูปเสียหาย พร้อมตรวจว่าไม่มี JavaScript errors หรือ requests ไปยังเว็บไซต์อื่น

## ขอบเขตการใช้งาน

- ทดสอบผ่าน WebKit จำลอง iPhone แล้ว แต่การบันทึกลง Photos และตั้ง Lock Screen บน iPhone จริงยังต้องตรวจบนอุปกรณ์จริง
- นาฬิกาและวิดเจ็ตเป็นภาพจำลอง ตำแหน่งจริงขึ้นกับรุ่น iOS การปรับนาฬิกา วิดเจ็ต และการครอปตอนตั้งวอลเปเปอร์
- HEIC/HEIF ใช้ได้เฉพาะเมื่อเบราว์เซอร์ถอดรหัสได้ หากเปิดไม่ได้จะแนะนำให้แปลงเป็น JPG
- รูปที่เล็กกว่าขนาดส่งออกอาจไม่คม และอุปกรณ์หน่วยความจำน้อยอาจมีข้อจำกัดกับรูปขนาดใหญ่
- ประมวลผลในเครื่องไม่ได้หมายความว่าเปิดเว็บครั้งแรกแบบ offline ได้ เว็บไม่มี service worker สำหรับติดตั้งหรือ cache offline
- ฟอนต์และการเกลี่ยขอบอักษรอาจต่างกันเล็กน้อยระหว่างระบบปฏิบัติการตามสเปกที่ยืนยัน

โครงการนี้ไม่ได้เชื่อมกับ Apple Music และไม่ได้เป็นผลิตภัณฑ์ของ Apple
