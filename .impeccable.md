## Design Context

### Users
People making personal iPhone Lock Screen wallpapers from their own photos and text. Editing on iPhone and desktop is equally important. The interface supports Thai (default), English and Japanese with a persistent language selector. Switching the interface language must preserve all user-authored wallpaper content.

### Brand Personality
Quiet, personal, considered. Working product name: still.

### Aesthetic Direction
User-approved references: spacious light desktop editor, portrait music-player wallpaper with square artwork, track metadata, playback ornaments, extracted color strip and optional credit. Warm graphite accent, subtle rules, generous whitespace. Apple-like system typography is explicitly preferred over decorative fonts.

Two wallpaper templates ship today: the original customizable-color player above, and a second
"Now Playing" dark template (auto-computed gradient background, rounded/shadowed artwork, no
manual color pickers) inspired by — but not affiliated with — Apple Music. See `CLAUDE.md` for the
full template registry and rules for adding more.

### Design Principles
- The wallpaper is the focal point; controls are secondary.
- Fixed composition per template, personal content. No freeform positioning or filters.
- Match preview and PNG using a shared canvas renderer.
- Keep images, processing and the latest draft on-device.
- Show lock-screen guides separately from exported artwork.
